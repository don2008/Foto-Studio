# FotoStudio

Natívna Android fotoaplikácia v Kotlin + Jetpack Compose a CameraX.

## Aktuálny prototyp

- živý náhľad zadnej kamery,
- prepínanie objektívov 0,5× / 1× / 2× / 5×,
- základné ovládanie zoomu cez CameraX,
- vodiace línie zlatého rezu,
- režim asistovanej kompozície,
- GitHub Actions build debug APK.

## Ďalší krok

Napojenie detekcie scény a výpočtu najlepšieho priblíženia podľa polohy hlavného objektu.
